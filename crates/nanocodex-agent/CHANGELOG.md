## [0.3.0](https://github.com/gakonst/nanocodex/releases/tag/v0.3.0) - 2026-07-26

### Added

- Own the cloneable agent handle, ordered prompt lifecycle, independently
  streamable and awaitable turns, steering, cancellation, spawning, forking,
  snapshots, rollouts, and per-driver tools.
- Report exact turn usage and optional estimates from immutable versioned USD
  pricing snapshots.
