# Nanocodex review client

This browser review client is derived from Tact v0.3.6
(`1d9ccaefd1d8613dab020812af04a91cd9b4c52c`) under Apache-2.0 and modified for
Nanocodex. See [`docs/TACT_UPSTREAM.md`](../../docs/TACT_UPSTREAM.md) for the
import and adaptation record.

Run `bun install --frozen-lockfile`, then `bun test`, `bun run build`, and
`bun run typecheck`.
